# Compatibility Matrix

本文件记录 `mac-folder-icon-replacer` 在不同 Agent、macOS 环境和权限状态下的真实验证结果。

## 判定状态

- **已验证**：完成全部端到端验收项，并保留可复核证据。
- **部分验证**：可以加载 Skill，但某一项必要能力需要人工完成或无法自动完成。
- **未验证**：尚未在目标 Agent 上完成真实测试。
- **不兼容**：无法加载 Skill，或缺少完成安全流程所需的关键能力。

## 统一验收项

每个 Agent 都必须按同一测试夹具执行以下项目：

1. 加载通用 `SKILL.md`。
2. 检查图像处理、Finder、剪贴板和文件系统权限。
3. 未获授权时停止，不操作目标文件夹。
4. 使用 `tests/skill-test-image.jpg`。
5. 生成透明背景 PNG。
6. 请求并确认测试目标文件夹。
7. 通过 Finder 替换文件夹图标。
8. 验证图标已更新。
9. 验证普通文件、嵌套目录和文件内容未改变。
10. 单独记录允许的 `Icon` 和 `.DS_Store` 系统元数据。
11. 生成测试结果和兼容性结论。

## 约束

- 没有真实测试证据时，不得将 Agent 标记为“已验证”。
- 不因为 Agent 能读取 Markdown 就推断它能控制 Finder。
- 不因为图像能被处理就推断剪贴板和 Finder 权限可用。
- 任何普通文件或子目录发生非预期变化，整体测试失败。
- macOS/Finder 为显示自定义图标生成的系统元数据应单独记录，不计入普通内容变更。
